# new iphone

## What

New iPhone. Decide model + storage, and whether to trade in the old one.

## Deniz's recommendation

[iPhone 17 256GB](https://www.apple.com/nl/shop/buy-iphone/iphone-17) — €969. Base model now starts at 256GB, which is enough; the €360 Pro premium only pays off if you shoot a lot of photo/video. If storage is the itch, a 512GB base (€1219) is still cheaper than a 256GB Pro.

Trade-in: [Apple Trade In](https://www.apple.com/nl/shop/trade-in) gives instant credit but NL values were cut twice in 2026 — get a serial-number quote and compare against Amac/leapp before accepting.
